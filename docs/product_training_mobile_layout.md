# 手机游戏布局

已有游戏仍使用同一份模型、关卡和控件；手机不另造一套参数或进度。

- 760px以下：关卡导航改为一行编号，保留完整可访问名称、锁定与通过状态。当前关卡标题照常显示。
- 电路画面、目标、器件/条件、启动或下一关按顺序相邻。画面高度230px；按钮不低于44px，不通过缩小点击范围省空间。
- 长原理说明、术语、详细指标合并进默认折叠的“原理与详细结果”。即时结果、未知条件反馈、亮度条、暂停/慢放/复位和额外必要动作仍保留。打开说明后可继续修改参数，说明使用原来的实时节点。
- 屏幕转宽后，原节点回到桌面位置；不克隆控件、不丢失监听器、参数、视角或通关记录。切换章节释放布局监听器。
- 不加入固定高度的滚动面板或额外滚动条。较复杂的多条件游戏仍可能需要少量页面滚动；不能承诺全部培训内容装进一屏。

验收：`python tools/check_training_mobile_layout.py [--public]`，采用已安装浏览器设备描述中的iPhone15Pro内容视口393×659、DPR3和触屏。验证开始、换件、过关的原生操作/完整屏幕截图，30章节单操作台与44px按钮、说明展开实时值、宽窄切换恢复原节点/进度和单外层滚动。Chrome模拟不是iPhone真机/Safari认证。完整关卡与实时动画回归仍使用原验收程序。
