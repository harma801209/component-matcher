# 培训页的统一学习顺序

全部7大类/30细项采用相同顺序，目录只表示定位，不表示已学会或已通关。

1. **认识器件**：原3D外观/内部材料模型与简短用途、常见应用。优先复用已有新手说明，不把参数表当作第一项内容。
2. **看懂电路作用**：基础章仍是原PCB分步演示；其他细项仍是各自应用/功能连接，不拿不同器件套同一个原理。
3. **动手闯关**：原3D闯关/自由实验。通过目录可直接展开游戏，原30细项/94关、4范例/14验证练习、参数、会话和销毁机制不变。
4. **参数与选型**：原规格/性能/原理三个知识标签；基础章原型号拆解、选型实战、错题本和选型提醒放在这一组。未扩大工具的覆盖范围。
5. **检查理解**：原小测验从参数标签中移出，独立在最后。复用原问题、答案、反馈及既有记录方式，不新增会员保存。原厂资料随后默认折叠，仍可展开查看全部链接和条件说明。

顶部五步目录和每组“学习目录”按钮只做原页内定位；没有新路由、内层滚动、学习计分或业务数据。保留原组件ID和事件，移动同一个模型/工具/题目DOM，不复制3D、重新创建题库或用CSS顺序与读屏顺序错位。模型仍能旋转、拆解和选择材料；参数实验保留数值和图表，必要时可回第一步对照模型。

知识区三个标签独立键盘循环；末尾小测验使用自己的单标签/面板语义，不会因切换参数标签而消失，答题完成文案也指向新的面板位置。目录目标为可聚焦标题，按钮≥44px；移动端目录两列，模型/用途上下排列，继续只用外层滚动。没有宣称完整无障碍合规或真实新人学习效果。

`training_journey.js`在原目录/课程初始化后移动现有节点，按当前细项更新用途卡片；`training_embed.js`继续负责 iframe 自适应高度。原程序无需依赖新导航即可运行，旧游戏、材料、参数和实战入口仍使用原ID。

验收：`tools/check_training_journey.py --before --public`捕获调整前；不加`--before`验证30细项固定五步、原生跳转、知识/小测验相互独立、材料/类型保持、1440/900/390排版和单滚动。另回归30章材料/参数/测验、原实战/错题记录、16+78关与新手范例、外层滚轮/高度扩缩，以及隔离发布安全门。私人截图/审查记录不进入发布。
