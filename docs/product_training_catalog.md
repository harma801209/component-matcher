# 七大类、30个产品细项

培训面向销售和助理。先选大类，再选产品细项；同一页面展示应用位置、接入后的电路作用、结构材料、规格重点、参数体验、原理与测验。只修改教学页面，不修改器件匹配、库数据或会员权限。

| 大类 | 当前常用品类 |
| --- | --- |
| 电容 | MLCC、铝电解、安规、薄膜、钽 |
| 电阻 | 厚膜、薄膜、采样、抗硫化 |
| 电感 | 绕线、贴片叠层、一体成型、共模 |
| 晶振 | 无源晶体、有源XO、温补TCXO、压控VCXO |
| MOS管 | N沟道、P沟道、双MOS |
| 二极管 | 开关、整流、肖特基、稳压、TVS、LED |
| 三极管 | NPN、PNP、达林顿、带阻数字三极管 |

以上是常用品类导航，不是穷尽行业产品的互斥分类。采样是用途，抗硫化是可靠性特性；安规是应用及认证要求；贴片是安装形式。N/P与双器件组合、NPN/PNP与带阻/达林顿也属于不同分类维度。选择区用一句话说明重叠关系。

## 模型和学习内容

- 保留厚膜电阻、MLCC、绕线电感、开关二极管的详细基础模型、电路分步动画、8个小游戏与原有选型实战/错题本。
- 新增26个细项章节，使用同一canvas与相机，支持拖拽、键盘/滚轮、自动旋转、编号选部位。内部模式可拆解，外观模式不暴露封装内的晶片、MOS栅层或半导体区。晶体封装底座可见，但不能按焊盘数判断有源/无源。
- 每个新增细项有自己的材料、规格、作用、客户需求问题、参数实验和三选一测验，不复用不适用的MLCC/PN结/基础游戏。肖特基画金属—半导体势垒；MOS与BJT使用不同材料分区和驱动条件。TCXO/VCXO电路说明分别显示补偿/调谐。
- 模型为典型结构与功能区示意，不是厂商CAD。颜色和薄层已放大；电解及薄膜卷芯局部展开、钽孔隙及涂层分区放大。外观与内部模式不同；内部标号对应下方材料，不用交叉引线。
- 新实验只计算明确给出的课堂条件：CL匹配不保证晶体启动、VGS阈值不保证MOS低导通电阻、TVS的VRWM不等于VC、BJT的hFE不保证饱和。TCXO/VCXO只做ppm预算/频率换算，不编造厂家温补或电压曲线。
- 新增应用图为功能连接关系，并明确高边/低边、并联保护支路、时钟与供电不同；不是电气设计或可生产布板图。参数数值不等于具体型号的额定保证。
- 新章节选择、参数和答题仅在当前页面内保留，刷新回到厚膜基础章；现有基础实战记录方式不变。无网络接口、无业务数据库或会员数据读写。

## 技术组织与验证

- `training_catalog.js`：冻结的分类及课程数据、分材料说明和厂家资料来源。
- `training_catalog_geometry.js`：复用原模型基础几何，生成细项外观/内部网格及编号锚点。
- `training_catalog_labs.js`：独立的有限参数计算，拒绝非法输入。
- `training_catalog_ui.js`：两级选择与学习内容呈现，四个基础章节恢复原功能。
- `training.js`：只在新细项模式扩展既有查看器，保留一个canvas；`product_training.py`按依赖顺序内嵌资产，不新增外部JS依赖。
- `tests/test_product_training.py`覆盖类别/30个课程完整性、N/P材料区别、冻结与非法ID、有限几何/封闭外观、所有参数选项与公式边界及单查看器。
- `tools/check_training_catalog.py`逐项验证30章、材料编号、实验/测验/来源、类别记忆、基础恢复与1440/900/390px单外层滚动；`--public`在正式入口执行。
- 继续运行既有基础小游戏、单滚动和实战回归。发布前运行隔离数据库安全门；发布后只读复核会员、客户、当前成本/历史与真实型号搜索。

资料依据保存在各章来源区，包括Vishay、TDK、Murata、KYOCERA AVX、Coilcraft、Epson、Infineon、ROHM、Littelfuse、ST与Nichia原厂文档。具体型号始终按原厂规格书确认材料、针脚与工作条件。
