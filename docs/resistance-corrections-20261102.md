  The table explicitly gives R10000 as 0.1 Ω.
- [Vishay ERC / RNC](https://www.vishay.com/docs/31025/erc.pdf),

This verifies the nominal meaning of the model string. It does not establish
availability, production status, certification, tolerances, power or suitability
of a physical part. Distributor listings may repeat the same imported typo and
are not used to override the original manufacturer numbering rule.

## Effective data and rollback

`resistance_corrections.py` applies the same exact-identity list to:

1. prepared catalogue records, including the already-prepared fast path;
2. a connection-local indexed resistor SQL projection;
3. lightweight model and BOM candidate detail records;
4. offline filter assets generated by `tools/build_catalog_ready.py`.

Display value/unit and numeric aliases are updated together. A public-field-only
original-value JSON and evidence URL are attached to corrected detail records.
Existing brand/model, tolerance, power, price and historical quotes are not
rewritten. No member, cost-list, report or job database is migrated or replaced.
The source public SQLite/parquet and original public bundle remain unchanged.

The SQL projection contains only the matching existing rows; it does not create
ordering codes. An indexed UNION removes each old identity once and retains its
original duplicates, then exposes its corrected counterpart. CROSS JOIN pins
the tiny reviewed set as the outer lookup loop rather than scanning the entire
resistor library during connection setup. Numeric queries retain the source
compound index plus the small correction index.

Rollback is a code/data deployment rollback together with its matching ready
manifest/assets, not restoration of protected runtime databases. Rebuilding
ready assets is required when the correction recipe changes.
