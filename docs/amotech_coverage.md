此版本增加 **363 个明确列出的 MLCC／宽带电容型号**，不是把编码字段排列组合后冒充产品目录。加上原有的 5 个压敏／保护器件，当前可浏览的 AMOTECH 目录合计 **368 个型号**。

| 分组 | 命名规则支持 | 实际目录型号 |
| --- | --- | ---: |
| MLCC | ACC、ACT、ACX、ACS、ACH、ACB、ACE、AC1、AC2、AC3、AC4、AC5、AC6，按原厂 Rev.10N | 345 |
| 宽带电容 | ABCUA、ABCUB、ABCUC，已核验设计／电压／材料／尺寸组合 | 18 |
| 高 Q／微波电容 | A60Z、A60L、A60S、A60F、A80B，容量／容差／耐压表约束 | 仅规则，不把订货示例或排列组合计入目录 |
| ESD／压敏／EMI | 已核验历史目录中 14 个系列的分段编码；识别并提示待核验，不进行普通 MLCC／TVS 替代 | 5（原有） |

**以上不是 AMOTECH 全部产品线已经完成。** ESD／EMI、RF 器件、固体电解质陶瓷，以及电机、天线／模块的完整、最新订货编码仍需相应原厂资料核验。官网产品介绍页不等于完整编码规则。AMOSENSE 的模块不能直接改成 AMOTECH 品牌。

## 原厂 MLCC 完整字段结构

来源：[原厂 Part Numbering，2026-06-09 Rev.10N](https://ts.amotech.co.kr/assets/productInfo/part-numbering-mlcc.pdf)，共 5 页；末页明确要求未列在目录中的料号订购前联系原厂。

示例分段：`AC | 1 | 02 | X | 02 | N | 106 | M | N | D | A`

| 字段 | 已实现含义 |
| --- | --- |
| AC | 陶瓷电容标识 |
| 材料 | C=C0G、T=X8G、X=X5R、S=X7R、H=高压 X7R、B=X7R(AMO)、E=X8R、1=X6S、2=X7S、3=X7T、4=X8S、5=X8L、6=X8T |
| 长宽 | 0X=01005、01=0201、02=0402、03=0603、05=0805、06=1206、10=1210、12=1812、20=2220；公制与英制分开存储 |
| 厚度 | X=宽度等于厚度；Z/A/B/C/D/E/F/G/H/J/K/L/M 为原厂厚度表；S/W/T 为框架堆叠结构，不能当成通用尺寸 |
| 电压 | 按原厂表映射；**2B 在第 1 页与第 4 页存在 250V 与 200/250V 标注差异，未找到具体型号依据时不猜测** |
| 设计 | N=Normal、P=Open、F=Floating、A=Acoustics、E=ESD |
| 容量 | 两位有效数字加指数（pF）；小容量 R 表示小数点 |
| 容差 | Z/P/T/Q/A/B/C/D 为绝对 pF；F/G/J/K/M 为百分比，不能混算 |
| 电极／端子 | N/F/W/G/T/M/V/P/E 的材料、软端子、镀层或金属框架含义按表解释 |
| 包装 | B=散装；D/J=180/330mm 纸带；L/K=180/330mm 压纹带；T=托盘 |
| 应用 | C=商用；G=工业／通信；A=汽车应用；**A 不自动等于已经通过 AEC-Q200** |

编码解析不等于该组合存在、可供货或正在生产。规则推导的未知型号不会进入库内数量，也不会产生价格。

## 宽带电容

现行原厂选型工具有 ABCUA、ABCUC 共 15 条记录。另有三份具体型号规格书补充旧编码：

- [ABCUA10201X104KNDG](https://www.amotech.co.kr/pdf/bro/ABCUA10201X104KNDG_Datasheet.pdf)
- [ABCUB10201X104KNDG](https://www.amotech.co.kr/pdf/bro/ABCUB10201X104KNDG_Datasheet.pdf)
- ABCUA06F0XX104MNDG：原厂署名 Rev.04（2020-12-08），由公开镜像保存，原文件 SHA-256 与镜像地址见数据清单。该型号是 **01005 / 0402 公制、100nF、±20%、6.3V**；F 是原厂内部材料代码，不能擅自写成 X7R。原厂给出的典型频段为 16kHz～40GHz+。

宽带电容与普通 MLCC 分离匹配。容量、耐压相同不代表宽带、插损、回损或 S 参数等效；不自动标成完全替代。

三份旧版具体型号规格书列出的是 TCC 测试温区，没有单独明确完整额定工作温度，故将该温区保存在来源备注，不填充为“工作温度”。现行网页型号的工作温度则直接采用选型工具的明确字段。

## 可重现数据流程

`tools/import_amotech_catalog.py` 从原厂网页可见表格导出和已核验的 PDF 表格提取生成 `catalog_sources/amotech_verified.json`，保存来源、提取日期、文档版本与 SHA-256。它不写任何数据库。

应用连接使用 TEMP 目录扩展，现有已入库记录优先，且保留江海参数补全。关闭连接后临时目录消失，不改写原始大型目录或会员、成本、回报数据库。
