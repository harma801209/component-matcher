# 电子维修店

独立于器件课程的综合训练。随机客人、产品和预设的可诊断故障组合；不是把任意测量值随机拼成一张工单。

## 完整回合

1. 从三个客人的工单里接单，原始症状始终保留。
2. 查看电路功能图和维修手册，选择板上器件，通电测电压或波形。
3. 断电、模拟放电和隔离后检测元件，记录实测与正常参考。
4. 用测量证据提交“位号 + 失效类型”，而不是盲目换件。
5. 根据手册选择兼容备件，并处理有极性器件的安装方向。
6. 通电进行功能测试和负载复测，通过后交付。采购扣金币，交付得金币及学习积分；同一工单不重复结算。

六种低压产品：USB红光小夜灯、桌面风扇、蓝牙音箱、电子钟、环境传感器、迷你路由器。每种三个故障模板，共18种。交付后解释故障证据及选型理由。

## 新手教学与师傅提示

首次游玩默认显示逐步教学，也可选择自己诊断，随时切换。每步说明点哪个器件、用哪个工具、要比较什么正常值；“带我找到这一步”仅滚动到对应控件并聚焦，不代替测量、选择诊断、购买或交付。手机工具区也显示当前操作指引。完成动作或刷新恢复后，教学按实际进度继续。

“师傅提示”针对当前产品和工单给出四部分：可能坏在哪里、为什么这样怀疑、如何检测出来、如何维修和验收。默认先说明排查方向；展开详细定位会明确提醒将透露故障位号、失效类型、异常/正常读数及具体换件规格，但仍需亲自收集证据。看完可点“回到维修操作”，不会自动执行动作。

术语随当前器件解释，例如OL、ESR、VGS、DCR和晶体负载电容。备件不兼容时说明不满足的条件，安装极性也需亲自核对。教学和提示均免费，不扣游戏积分；仅操作错误影响本单评分，不更改已结算历史积分。积分与奖励仍仅限游戏内。

## 测量证据与验收对照

点板上器件或测量目标，不再同时填入故障答案。诊断下拉框仅由玩家亲自选择；读数旁解释这是节点电压、整机运行线索还是隔离元件证据。板上与目标按钮的状态仅来自已经取得的测量记录，不在未测量时标出预设坏件。通电电压异常不等于所选元件损坏。

笔记区保留维修前、换件后的实际手动测量记录。更换后先显示待验收，通过原有功能与负载测试后，才生成“维修前后对照”：一项目标元件隔离复测、三个供电测试点、整机功能与负载结果。验收列由本关测试程序的修复后模型生成；维修前列只能采用玩家测过的记录，缺少的明确显示“未记录”，不回填隐藏故障数据。

验收面板同时显示备件成本、工单报酬及预计净收益。查看面板不会发放金币，仍须按原规则交付，一单仅结算一次。对照与证据为只读呈现，不新增存档字段，不改变已有进度、经济规则或会员/成本数据。

## 教学边界

- 功能连接图省略非诊断电路；测量数据是本关给定的简化模型，不是这些商品的真实维修数据。
- 电阻：同阻值、同封装，精度不低于要求，额定功率满足要求。
- 电容：容量、类别、封装、耐压、ESR与极性均须符合本关手册；不宣称只看容量与耐压就能任意替代。
- 半导体、保险丝、晶体和电感：具体系列/引脚/响应/驱动/负载条件按本关给出的兼容清单核对；额定参数更大并非自动兼容。
- 电阻/电容测试需断电、放电且隔离，游戏自动模拟隔离，不把在路测量当成唯一元件真值。
- 不包含市电、高压、锂电池拆修指导，不提供真实设备带电维修教程。

测量规则参考：[Fluke电阻测量](https://www.fluke.com/en-ie/learn/blog/digital-multimeters/how-to-measure-resistance)、[Fluke电容测量](https://www.fluke.com/en-us/learn/blog/digital-multimeters/how-to-measure-capacitance)。电容类型/选型边界参考：[Murata电容选型](https://www.murata.com/products/capacitor/selectionguide)。具体关卡数值与备件编号为教学设定，不对应原厂可采购型号。

## 存档与兑换

浏览器本机存档，存储被禁用时退回本次会话并明确提醒。金币、积分、奖励均为游戏内内容，不关联会员账户、价格数据或真实礼品。刷新后恢复未完成工单；多窗口变更时重新读取较新存档，防止旧页面重复结算。玩家仍能自行修改浏览器数据，因此不能将本地积分用于真实兑换。

第一版兑换为维修桌配色、店铺招牌和纪念奖章。真实商品兑换、后台账本、活动库存及反作弊需独立设计后才能接入。

LED案例使用红光小夜灯与约2V压降的简化模型，避免把白光LED普遍视为2V器件。参考：[Kingbright LED电气特性表](https://www.kingbrightusa.com/webimages/2021/catalog/Kingbright%202022-2023%20Catalog.pdf)。旧版“USB阅读台灯”的本机维修履历兼容映射到“小夜灯”，不清除既有成绩。
