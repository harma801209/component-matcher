# 电子维修店

独立于器件课程的综合训练。随机客人、产品和预设的可诊断故障组合；不是把任意测量值随机拼成一张工单。

## 零基础三章（2026-10-23）

大厅“第一次修好它”和页头“新手三章”进入独立练习；已接工单无需撤销，随时可以返回。

1. USB小夜灯：师傅已安全拆开放到桌上，预接教学诊断夹具；玩家亲自记录通电结果、断电放电、选择器件做隔离检查、判断开路、按规格选件并通电验收。不是普通万用表可以任意接线的演示。
2. 留下首次预测，再比较同一5 V电源与红色LED、串联220 Ω / 440 Ω的两组实际计算记录。复用非线性LED电路求解器，约13.77 / 7.00 mA；不把电流关系机械地算成精确一半，不虚构照度。440 Ω是实验条件，不算原机合格维修推荐。
3. 书桌提示灯改用180 Ω手册值，故障为阻值偏移。减少逐步指定，需要自己取得通电及隔离证据、选件、复测。报告分别标记使用提示、修改后完成、未用提示首次判断与选件通过，不颁发“已掌握全部器件”结论。

三章存档键`fruition.repair-shop.first-steps.v1`与原游戏完全分开；只重放有效操作恢复，不信任保存的完成标记。不会调用正式工单经济事件、扣发金币积分、写会员/成本库或履历。可二次确认后重新练习；自由维修的完整拆装、手动表笔和奖励规则不变。

手机把电路和当前操作放在同一屏范围内，操作面板可单独滑动；嵌入场景按可信宿主的可见高度计算，不用自动增高iframe的`vh`。3D电阻标记使用已有真实编码器，随180/220/440 Ω等实际标称值改变。

验证：`python -m unittest tests.test_repair_shop_first_steps`；Chrome实际点选`tools/check_repair_shop_first_steps.py`，手机加`--mobile --embedded`，可加`--width 360 --height 640`。覆盖三章、首次预测保留、错误诊断/备件、刷新恢复、手机同屏、正式工单和经济不变。估计时长与留存改善尚需真实零基础用户试玩验证。

## 动手维修扩展（2026-10-23）

- **全屏维修**：自由工单页头进入/退出。支持时使用浏览器原生全屏；受嵌入权限限制时使用可信宿主内的沉浸布局。手机横屏让电路板与独立滚动的工具栏并排。退出后恢复原来的宿主样式及培训自动高度，不改其他页面。
- **按住拧螺丝**：先断电放电、拿螺丝刀。对准3D螺丝按住，或按住对应工具按钮/Enter/空格；松手暂停。可逐次点“转1/4圈”。完成前不写拆装事件，完成后才转移螺丝，旧M事件与存档兼容。两圈只是本关交互进度，不代表真实螺纹圈数、扭矩或损伤模型；未完成的手势进度不跨刷新保存。
- **模型示波器**：通电并连接缓冲诊断口后，手动记录波形。音箱RC和路由器RLC支持规定周期纹波、负载阶跃和无负载网络上电实验，后者不代表整机启动。允许半幅实验负载，但不改工单验收条件。其他产品只展示已建模的直流稳态，不伪造启动、时钟或开关噪声。曲线使用现有网络参数及精确状态传播；端电压允许ESR导致跳变，理想电容内部电压和电感电流连续。只保存工况描述，不向存档写大量采样数组。
- **分步换件**：核对备件→拆旧→焊盘检查→方向→放置新件→焊点检查→确认安装记账→通电复测。半装期间禁止电气测量和通电；开始换件不扣钱，最终安装只扣一次。旧件留桌，拆下和放置动作有3D过程。步骤示意不模拟实际焊接热过程、材料、温度、时间或工艺合格性。旧工单的直接安装事件仅为原有API/存档兼容保留，新界面不会以一次点击替代分步流程。
- **报告及客户反馈**：保留原有症状、测量证据、原因、换件规格与验收链，补充实际记录的换件步骤；缺少的旧操作不补写。完成交付才显示对应客户反馈，时钟不宣称走时已验证、路由器不宣称网络功能已验证，不追加奖励或重复结算。

验证：`tests.test_repair_shop_hands`覆盖手势边界、17种已开放故障的新流程、单次扣费/结算、回放、旧事件、RC/RLC采样与原求解器一致、独立RK4对照及宿主样式恢复。`tools/check_repair_shop_hands.py`用实际浏览器检查横屏同屏、按住/暂停/续拧、示波器、分步换件与报告；结合原有完整回合、教学、新手三章、所有板和手机版检查回归。

上电和改负载曲线是理想源直接激励的独立等效网络实验；输入模块、控制环路和输入负载不参与该实验，不能据此宣称整机瞬态或功率验收通过。仪表原数字摘要仍对应原工单规定工况。

边界参考：[Fullscreen规范](https://fullscreen.spec.whatwg.org/)和[MDN嵌入全屏权限](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Permissions-Policy/fullscreen)；不能通过子iframe自行扩大父文档权限。[TI负载瞬态与电容/ESR](https://www.ti.com/document-viewer/lit/html/SSZTCQ4?DCMP=fc&HQS=pwr-null-null-powertips-pwrhouse-20150721-blog-20150514-wwe)支持将负载变化、储能与ESR区分；这里仍仅计算声明的等效网络，不模拟完整控制器。

1. 从三个客人的工单里接单，原始症状始终保留。
2. 查看电路功能图和维修手册，选择板上器件，通电测电压或波形。
3. 断电、模拟放电和隔离后检测元件，记录实测与正常参考。
4. 用测量证据提交“位号 + 失效类型”，而不是盲目换件。
5. 根据手册选择兼容备件，并处理有极性器件的安装方向。
6. 通电进行功能测试和负载复测，通过后交付。采购扣金币，交付得金币及学习积分；同一工单不重复结算。

六种低压产品：USB红光小夜灯、桌面风扇、蓝牙音箱、电子钟、环境传感器、迷你路由器。每种三个故障模板，共18种。交付后解释故障证据及选型理由。

## 新手教学与师傅提示

首次游玩默认显示逐步教学，也可选择自己诊断，随时切换。每步说明点哪个器件、用哪个工具、要比较什么正常值；“带我找到这一步”仅滚动到对应控件并聚焦，不代替测量、选择诊断、购买或交付。手机工具区也显示当前操作指引。完成动作或刷新恢复后，教学按实际进度继续。

“师傅提示”针对当前产品和工单给出四部分：可能坏在哪里、为什么这样怀疑、如何检测出来、如何维修和验收。默认先说明排查方向；展开详细定位会明确提醒将透露故障位号、失效类型、异常/正常读数及具体换件规格，但仍需亲自收集证据。看完可点“回到维修操作”，不会自动执行动作。

术语随当前器件解释，例如OL、ESR、VGS、DCR和晶体负载电容。备件不兼容时说明不满足的条件，安装极性也需亲自核对。教学和提示均免费，不扣游戏积分；仅操作错误影响本单评分，不更改已结算历史积分。积分与奖励仍仅限游戏内。

## 测量证据与验收对照

点板上器件或测量目标，不再同时填入故障答案。诊断下拉框仅由玩家亲自选择；读数旁解释这是节点电压、整机运行线索还是隔离元件证据。板上与目标按钮的状态仅来自已经取得的测量记录，不在未测量时标出预设坏件。通电电压异常不等于所选元件损坏。

笔记区保留维修前、换件后的实际手动测量记录。更换后先显示待验收，通过原有功能与负载测试后，才生成“维修前后对照”：一项目标元件隔离复测、三个供电测试点、整机功能与负载结果。验收列由本关测试程序的修复后模型生成；维修前列只能采用玩家测过的记录，缺少的明确显示“未记录”，不回填隐藏故障数据。

验收面板同时显示备件成本、工单报酬及预计净收益。查看面板不会发放金币，仍须按原规则交付，一单仅结算一次。对照与证据为只读呈现，不新增存档字段，不改变已有进度、经济规则或会员/成本数据。

## 教学边界

手机上，3D画面下方有紧凑的拆装/台架操作栏：逐次点击拿工具、拆螺丝、开盖、取板；接表笔、开关电源和记录测量也可在画面旁完成。“全部工具”进入完整工具区。会改变场景的操作完成后自动回到画面，避免错过拆装动画。所有动作仍需手动确认，不代选故障、不自动买件或测量。

拿着表笔时可按Q/E转向，或点左右转按钮；已连接的表笔也能调整握柄朝向，笔尖接点不变。右键/中键仍用于转视角，旋转时不会隐藏手上的表笔。软线从笔尾弯向桌边；这只是视觉效果，不模拟软线碰撞和受力。

- 功能连接图省略非诊断电路；测量数据是本关给定的简化模型，不是这些商品的真实维修数据。
- 电阻：同阻值、同封装，精度不低于要求，额定功率满足要求。
- 电容：容量、类别、封装、耐压、ESR与极性均须符合本关手册；不宣称只看容量与耐压就能任意替代。
- 半导体、保险丝、晶体和电感：具体系列/引脚/响应/驱动/负载条件按本关给出的兼容清单核对；额定参数更大并非自动兼容。
- 电阻/电容测试需断电、放电且隔离，游戏自动模拟隔离，不把在路测量当成唯一元件真值。
- 不包含市电、高压、锂电池拆修指导，不提供真实设备带电维修教程。

测量规则参考：[Fluke电阻测量](https://www.fluke.com/en-ie/learn/blog/digital-multimeters/how-to-measure-resistance)、[Fluke电容测量](https://www.fluke.com/en-us/learn/blog/digital-multimeters/how-to-measure-capacitance)。电容类型/选型边界参考：[Murata电容选型](https://www.murata.com/products/capacitor/selectionguide)。具体关卡数值与备件编号为教学设定，不对应原厂可采购型号。
