# 游戏目标、知识反馈与同条件对比

开始时保留一个目标和一条操作提示；词义、固定条件和深入原理仍可展开。通关后把同一个目标位置改为本关知识（“可以这样向客户解释”），不在操作区重复完成、通过和解锁。进度数字和关卡导航仍保留；检查与授予通关的数学规则未修改。

`training_game_feedback.js` 只读取现有模型，构建一组“调整前 / 调整后”；不储存学习记录，不授予通关，不调用服务。普通关卡断电时不显示试算表；再次供电显示最近一次本关的比较。换关、换模式、换器件章节和重新制作清除比较，不清除原有通关记录。同选项重复点击不覆盖上一次有效比较。

电阻按相同5 V供电比较阻值、电流与相对灯光，隐藏重复的单条亮度读数。电容按相同补电需求比较末端电压；改变位置只比较接线长度，不虚构距离压降。电感按相同3 V/20 µs比较末端结果，触及Isat标为不再预测。其他细项按同一题设观察终点比较原模型的读数，保留缺参数、不预测和定性结果；不是所有状态都有灯光。综合作品的电容比较采用相同满充条件、断电2秒的RC结果试算，与正在运行的动画明确区分。

验收使用 `tools/check_training_feedback.py --phone` 和 `--public --phone`，桌面去掉 `--phone`。`--before` 只捕捉旧版本流程。原94关、14次练习和5步作品继续使用 `tools/check_training_power.py --full` 回归；单元测试与发布数据保护仍由 `tools/run_release_safety_gate.py` 执行。手机尺寸、触控模拟不等同真机Safari验证。
