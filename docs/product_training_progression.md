# 器件学习 → 综合电路

第3学习阶段现在只有`games-card`一个游戏模块，不再并列两个游戏卡片。同一模块中切换“器件学习关卡”与“综合电路”，同时只显示一个工作台。

## 小夜灯前置

厚膜电阻4关 + 肖特基二极管3关 + 铝电解电容3关 + N沟道MOS3关，共13关全部通过，才可进入原5步小夜灯产品章节。不要求学习未用到的电感、晶振或三极管；这不是所有30细项的统一硬门槛。

未解锁时给出尚缺器件、已完成关数与“去学习”入口。所需器件末关的主按钮自动指向下一缺少的器件；最后一个完成后指向综合电路。“再练一遍”仍可使用，不取消已获得的解锁。已完成的器件也可直接复习。

所有30细项仍有原有独立学习关卡。项目所需器件保存在`training_game_progress.js`的项目清单中；目前只有已实现的小夜灯，没有展示尚未实现的复杂电路。

## 成绩与存储

- 经原游戏引擎的实际操作、完整观察与目标判定通过才记成绩；自由实验、小测验、只打开页面不记成绩。
- 新键`fruition.training.lessons.v1`保存器件完成数与通过时的条件。读取时重新验证对应关卡模型、参数和观察状态；未知ID、版本、非法参数或未观察完的记录不用于解锁。
- 下一次进入部分完成器件，从下一未通过关的初始条件继续；全关通过时恢复已验证的完成示例。正在尝试但尚未过关的临时调整不保存。
- 成绩单调保留；重玩当前章节、另一标签页的旧成绩，不会取消先前解锁。损坏JSON可在下一次完成时修复当前键。
- 旧小夜灯键`fruition.training.nightlight.v1`原样保留，但不能代替器件前置。此前作品进度不会丢失；学习前置后可继续。
- 无浏览器存储仍可在本页学习并解锁，会说明刷新需重来。没有会员或跨设备同步，没有业务数据库、价格或网络写入。

前置是浏览器本地学习流程，不是防篡改证书或账号权限判断。
