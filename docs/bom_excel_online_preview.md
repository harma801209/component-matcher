# BOM匹配后Excel在线打开

结果页并排保留两个操作：在线打开Excel（新标签页、只读）和下载Excel（原另存/下载行为）。
预览读取现有`_bom_export_bytes`，不是当前筛选或分页的DataFrame。因此可查看导出文件中全部可见数据工作表和全部行，支持工作表切换、查找、分页及横向滚动。初始定位到结果页正在查看的工作表。

不改匹配、价格、导出逻辑或工作簿内容；不计算公式，不上传Office/Google等第三方，不生成公开文件URL，也没有跨用户预览缓存。
保留原文件隐藏表/行列设置，不自动取消隐藏。图表、宏、合并排版等特殊格式应下载后用Excel查看。
已有公式保存值会直接显示；缺少缓存值的公式显示原式并明确提示，不伪造零值或计算结果。

浏览器使用临时Blob页面，打开动作不触发文件下载。预览页下载和原按钮下载保持同一份原始字节。
单元格、表名、文件名作为文本显示，脚本JSON转义，忽略原表外部超链接，预览页限制网络连接。
大文件/不支持文件会明确停用在线预览，原下载仍保留；不静默截断数据。
当前上限：压缩文件16MiB、解包总量128MiB、XML单件32MiB、有效矩形合计50万单元格、单表100000行/256列及序列化内容20MiB。

验证：`tests.test_bom_excel_preview`覆盖完整数据、格式、隐藏设置、缓存/未缓存公式、XSS、原字节不变和降级。
`tools/check_bom_excel_preview.py`使用真实Chrome点击，在跨来源的双层iframe和Streamlit式sandbox下检查新标签页、不自动下载、3个可见页签、223行末行/查找和两个下载的字节一致性；含手机尺寸模式。
仅使用合成数据和临时下载目录，不访问或重置会员/价格/未匹配数据库。
